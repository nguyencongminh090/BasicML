### 3. AI Audit workspace design
- **Task:** Design a "modern project management" workspace for AI agents: fix-log (timestamp/prompt/action/decision/conclusion), a TODO list (with source, description, requirement), instructions linked to TODOs by ID for chat-session solution notes, and a conversation index letting an agent find/load past conversations by topic. Explicit constraint: must scale to 100+ TODOs without an agent forgetting or making mistakes.
- **Decision:** Placed the workspace at repo root as `ai-audit/` (tool-agnostic, not nested under `.claude/`) since it's an audit trail that should be versioned and readable by any agent tool. Core design principle: every folder has a bounded `INDEX.md` table that must be read before any individual item file — agents are told never to scan the whole tree. Active/archive split for `todo/` keeps the live index short forever regardless of total history. Stable, non-reused IDs (`TODO-XXXX`, `FIX-XXXX`, `CONVO-XXXX`) allocated via a script rather than hand-guessed, to prevent collisions at scale.
- **Fix:** Built out `ai-audit/README.md` (full schema), `ai-audit/scripts/next_id.sh` (ID allocator), templates and indexes for `fix-log/`, `todo/` (+ `archive/`), `instructions/`, and `convo/`. Added `.claude/skills/ai-audit/SKILL.md` (+ `.agents/` copy) as the operating manual so agents actually discover and follow the system, plus `/todo-add` and `/fix-log` slash commands. Wired `write-logs` (both `.claude/` and `.agents/` copies) to append a row to `ai-audit/convo/INDEX.md` whenever it saves a session log, closing the loop between "save log" and "find that conversation later." Updated root `CLAUDE.md` and `.agents/AGENTS.md` to reference `ai-audit/`.

- **Question/Task:** Verify the ID-allocator script actually works before calling the setup done.
- **Decision/Fix:** Found that `next_id.sh` silently exited with no output on an empty backlog — `set -euo pipefail` caused the script to abort when `grep -r` found zero matches (non-zero exit from `grep` inside a pipeline feeding a `$(...)` assignment). Fixed by appending `|| true` to that assignment. Verified empty-backlog case now correctly returns `TODO-0001`/`FIX-0001`/`CONVO-0001`, and that IDs increment correctly once entries exist. ## Key Takeaways
1. `ai-audit/` intentionally lives at repo root, not inside `.claude/` — it's an audit trail meant to be versioned and tool-agnostic, not Claude-Code-specific tooling.
2. The scale requirement (100+ TODOs, agent must not forget/mistake) was solved with two mechanisms: bounded `INDEX.md` tables that must be read before any individual file, and an active/archive split so the live index never grows unbounded.
3. Scripts that allocate IDs from `grep` output need explicit `|| true` under `set -e`/`pipefail` — a clean/empty state (zero matches) is a normal case, not an error, and must not abort the script.
4. `.claude/` was deliberately git-tracked per explicit user choice, unlike `.agents/`/`.gemini/` which stay local-only — this repo now has two parallel skill sets by design, kept in sync manually.
