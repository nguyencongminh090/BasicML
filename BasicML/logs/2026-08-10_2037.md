## Key Discussions

### 1. Current state of `basicml.nn`
- **Question/Task:** User asked what can be done with a Neural Network (Deep model) in this project.
- **Decision/Fix:** Explored `basicml/nn/` and `basicml/optim/`. Found the framework currently only supports single-layer models: `Linear` hardcodes output shape `(features, 1)` (no `out_features` param), there is no `Sequential`/container to chain layers, and `Loss` only has `MSELoss`/`BinaryCrossEntropy` (no multi-class `CrossEntropyLoss`). Concluded true deep/MLP models are not yet buildable without code changes — user deferred any code changes.

### 2. Usage of Deep Neural Networks / MLP (general, not code-specific)
- **Question/Task:** User clarified they wanted usage/theory, not implementation — asked what an MLP can be used for.
- **Decision/Fix:** Answered with input→output flow framing across regression, binary classification, multi-class classification, feature extraction/embedding, and general function approximation, plus when a simple linear model is preferable (interpretable, linearly separable data, few features).

### 3. Conceptual distinction: linear plane vs. deep non-linear mapping
- **Question/Task:** User proposed that ML/DL fundamentally draws a line/plane to separate data (classification) or as a regression surface (prediction).
- **Decision/Fix:** Clarified that this description is accurate for linear/logistic regression only. Deep networks instead apply successive non-linear transformations (via activations like ReLU/Sigmoid) that warp the data into a new feature space where a simple plane becomes separable — the final layer draws the plane, but in a *learned* transformed space, not the original one. Noted that stacking `Linear` layers without non-linear activations between them collapses back to a single linear transformation (no added representational depth).

## Key Takeaways
1. This project's `basicml` framework is currently limited to single-layer (linear/logistic regression) models — deep MLP support would require generalizing `Linear` and adding a layer-chaining container.
2. Deep Neural Networks differ from linear models not by drawing a more complex plane, but by learning a sequence of non-linear transformations that reshape the data space so a simple plane suffices at the final layer.
3. Non-linear activations between layers are what give a network "depth" in representational power; without them, stacked linear layers reduce to one linear transformation.
