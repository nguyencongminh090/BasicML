## Description

Add convolutional-network building blocks to `basicml/nn/` in the existing
manual-backward, PyTorch-inspired style: `Conv2D`, pooling layers
(`MaxPool2D`, `AvgPool2D`, `GlobalAvgPool2D`, `GlobalMaxPool2D`), a `Flatten`
layer, and a composite `CNNModel` in `nn/models.py`, plus an end-to-end
example script training a tiny CNN on a small synthetic image dataset.

## Requirement

- `nn/conv.py` — `Conv2D` subclassing `nn.Module`. Params `w` shape
  `(out_ch, in_ch, kH, kW)` (He/Xavier via `init=`), `b` shape `(out_ch,)`,
  both `requires_grad=True`. PyTorch-like API: `stride`, `padding`,
  `dilation` each `int` or `(h, w)`; `groups=1` only (documented limit).
  Implementation via vectorized slicing: loop over the `kH*kW` kernel taps
  only, each tap a strided/dilated slice with a vectorized accumulate over
  `(N, out_ch, H_out, W_out)`. `backward(grad_output)` mirrors the tap loop,
  accumulates `w.grad` / `b.grad` with `+=`, scatter-adds into a padded `dx`
  buffer, then un-pads. `forward` caches the padded input.
- `nn/pool.py` — `MaxPool2D` (cache argmax, route grad to max only),
  `AvgPool2D` (spread `grad_output / (pH*pW)`), `GlobalAvgPool2D` /
  `GlobalMaxPool2D` (reduce each channel to a scalar). Same `stride` /
  `padding` handling as `Conv2D`.
- `nn/flatten.py` — `Flatten` `(N, C, H, W) -> (N, C*H*W)`, cache input
  shape, `backward` reshapes back.
- `nn/models.py` — `CNNModel` composite in the `LogisticRegressionModel`
  mold: `Conv2D -> ReLU -> Pool -> Flatten -> Linear -> Sigmoid` (exact
  stack finalized during implementation), manually chaining each layer's
  `backward` in reverse.
- Core-module style: zero `#` comments, zero docstrings, column-aligned
  imports; keep `raise RuntimeError("backward called before forward pass")`
  guards.
- `examples/train_cnn.py` (or `demo/`) — tiny CNN on a small synthetic
  image dataset, standard `forward -> loss -> loss.backward ->
  model.backward -> optimizer.step -> zero_grad` loop; verifies the
  hand-derived gradients converge.
- `pyrefly check` clean; example script runs end-to-end.
