## Description

Start a new sibling project, `AdvanceML/`, alongside `BasicML/`: a from-scratch, performance-oriented deep learning library in modern C++ (C++20/23) with a real autograd engine (define-by-run computation graph + `.backward()`), backed by Intel oneDNN to exploit this machine's AVX-512 VNNI for GEMM/conv. Motivation: BasicML's pure-NumPy, manual-backward design cannot run CNN/Transformer-scale workloads efficiently on this CPU. BasicML is unaffected — it keeps its teaching purpose and manual-backward design.

This TODO covers the **project scaffold only**: CMake build wired to oneDNN, directory skeleton (`include/`, `src/`, `tests/`), a Catch2 smoke test, project README, `.gitignore` entry, and the new `## AdvanceML` section in root `CLAUDE.md`. The actual `Tensor`/autograd graph/backward engine and oneDNN-backed ops are out of scope here and get their own follow-up TODO(s) once the scaffold builds cleanly.

## Requirement

- `cmake -B AdvanceML/build -S AdvanceML -G Ninja && cmake --build AdvanceML/build` succeeds with no errors.
- `ctest --test-dir AdvanceML/build` runs and passes a placeholder Catch2 smoke test.
- Root `CLAUDE.md` documents AdvanceML's purpose, build commands, architecture direction (oneDNN backend, autograd not manual backward), and code style, without altering any BasicML-specific rules.
- `ai-audit` trail exists per the mandatory-trigger rule (this file, its instructions note, and a fix-log entry once verified).
