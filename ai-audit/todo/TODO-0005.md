## Description

Add a `BasicML/demo/` animation that visualizes a deep MLP as an evolving neuron
graph during training: per-layer weight heatmaps plus a sparse node-edge graph
(top-k edges by magnitude), animated with `FuncAnimation` in a single live
window. Show the effect of Dropout + L2 regularization via a side-by-side
comparison of two models with identical weight initialization (plain vs
Dropout + L2).

## Requirement

- One runnable file `BasicML/demo/plot_dynamic_mlp_graph.py`, run directly with
  `python` (self-inserts `BasicML/` onto `sys.path`).
- Deep model, default `[n_features, 64, 64, 64, 32, 1]`, ReLU hidden + Sigmoid out.
- Real dataset: sklearn `load_breast_cancer` if importable, else fall back to
  `basicml.datasets.make_moons`. No hard sklearn dependency.
- Uses existing library primitives only (`Sequential`, `Linear`, `Dropout`,
  `L2`, `Momentum` with `regularizer=`); no changes to `basicml/`.
- Left column plain, right column Dropout + L2, identical init; shared
  loss + val-accuracy curves; running penalty R(theta) shown.
- Repo conventions: Vietnamese comments, English identifiers, column-aligned imports.
