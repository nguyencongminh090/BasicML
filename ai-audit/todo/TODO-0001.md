## Description

Add multi-layer perceptron (MLP) support to `basicml.nn`: a `Sequential`
container that chains modules for forward/backward, a proper weight-init
module (`init.py`) that samples fresh from Xavier/He normal distributions,
and a `Linear` layer with an optional `bias` flag. Review and harden the
hand-written backward passes.

## Requirement

- `Sequential` drives forward and reverse-order backward, aggregates
  `parameters()`, and exposes `zero_grad()`.
- `init.xavier_normal_` / `he_normal_` draw new samples (not rescale), and
  handle 1-D tensors without crashing.
- `Linear` supports `bias=False`; parameters/forward/backward respect it.
- Numerical gradient check passes for `Linear` and a small MLP.
