# Description

Extend `BasicML/basicml/nn/activation.py` with more activation layers. The user
had already written the base `Activation` class plus `Sigmoid`, `ReLU`, `Tanh`;
the AI adds the rest following the same manual-`backward` convention.

# Requirement

- New layers, each an `Activation` subclass with `forward` + hand-derived
  `backward`, Google-style docstrings, teaching-oriented math notes:
  `Identity`, `LeakyReLU`, `PReLU` (learnable slope, real `parameters()`),
  `ELU`, `SELU`, `Softplus`, `GELU` (tanh approx), `Swish`/SiLU, `Mish`,
  `Hardtanh`, `Hardsigmoid`, `Softmax` (row-wise, closed-form JVP backward).
- Numerical gradient check passes (max abs error < 1e-4) for every layer,
  including PReLU's slope gradient and per-feature slopes.
- Composes inside `Sequential`; `pyrefly check` introduces no new errors.
