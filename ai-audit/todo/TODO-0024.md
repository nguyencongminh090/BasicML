## Description

Implement the Muon optimizer (MomentUm Orthogonalized by Newton-Schulz) as a new `basicml.optim.Optimizer` subclass in `BasicML/basicml/optim/muon.py`. Muon takes a momentum-accumulated gradient for each 2D+ parameter (weight matrices) and orthogonalizes it via a quintic Newton-Schulz iteration before scaling and applying the update; 1D parameters (biases) fall back to plain SGD-with-momentum since orthogonalization is undefined for vectors. Wire the new optimizer into `BasicML/examples/train_optimizer_comparison.py` alongside the existing optimizers.

## Requirement

- `basicml/optim/muon.py`: `Muon(Optimizer)` — momentum buffer per parameter, Nesterov-style lookahead, Newton-Schulz orthogonalization (5 steps default) for `ndim >= 2` parameters, spectral scale factor `sqrt(max(1, rows/cols))`, plain momentum update for `ndim < 2` parameters. Core library file stays bare (no comments/docstrings), matches the existing `Optimizer` subclass conventions (`regularizer` support, `zero_grad`).
- Added to the `OPTIMIZERS` dict / import list in `train_optimizer_comparison.py` so it runs in the comparison.
- `pyrefly check` passes; the comparison example runs end-to-end without errors.
