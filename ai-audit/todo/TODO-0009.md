# Description

Extend `BasicML/basicml/optim/` beyond the existing `SGD` / `Momentum` with more
gradient-descent optimizers, and add mini-batch support so the training loop can
do mini-batch gradient descent.

# Requirement

- New `Optimizer` subclasses, each its own file, bare core style (no comments,
  no docstrings), regularizer support and the `param.requires_grad and
  param.grad is not None` guard like `Momentum`:
  `Adagrad`, `RMSProp`, `Adadelta`, `Adam`, `AdamW` (decoupled weight decay),
  `Nesterov` (NAG).
- Mini-batch: `iter_minibatches(X, y, batch_size, shuffle, drop_last,
  random_state)` generator in `basicml/datasets/` (documented "library edge"
  package — Google-style docstring), exported from `datasets/__init__.py`.
- New example `BasicML/examples/train_optimizer_comparison.py`: same MLP / init /
  data, mini-batch GD, one training-loss curve per optimizer.
- `examples/train_linear.py` + `examples/train_logistic.py` switched from
  `Momentum` to `Adam` (lr / epoch budgets retuned).
- `BasicML/demo/` scripts switched from `Momentum` to `Adam` (cost-surface
  trio's `OneCycle` reduced to an lr-only schedule, "Momentum Path" trace
  renamed "Optimizer Path"), except `plot_dynamic_vanishing_gradient.py` which
  stays on `Momentum` (Adam masks the effect the demo shows).
- `pyrefly check` introduces no new errors; the example runs end-to-end.
