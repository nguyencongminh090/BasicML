## Description

Extend the CNN visualization work (TODO-0019) with a *trained* version: fetch
real MNIST via `scikit-learn`, train a small `basicml.nn` CNN classifier on
it, and animate how one fixed digit's feature maps evolve epoch-by-epoch
from random-init noise toward trained filters.

## Requirement

- New multiclass `CrossEntropyLoss` in `basicml/nn/loss.py`, matching the
  existing bare, no-comment/docstring style of `BinaryCrossEntropy`; its
  gradient chained through `Softmax.backward` verified numerically
  (`max abs diff` vs. finite differences: ~2.7e-10; matches the
  `probs - y_true` identity to ~1.1e-8).
- New `BasicML/demo/plot_dynamic_cnn_feature_maps.py`: fetches MNIST via
  `sklearn.datasets.fetch_openml`, trains `Conv2D->ReLU->MaxPool2D` x2 ->
  `Flatten->Linear->Softmax` (manual backward, Adam optimizer) on a subset,
  records one fixed sample's conv1/conv2 feature maps every epoch, and
  animates the recorded snapshots with `matplotlib.animation.FuncAnimation`.
- `scikit-learn` declared as a new dependency in the root `CLAUDE.md`
  (Commands section), scoped explicitly to being a dataset fetcher only —
  no `sklearn` estimators/training code, keeping the "from-scratch" rule
  intact.
