## Description

Add a reusable training-progress display that prints a PyTorch-style per-epoch
line with the loss **and** any `basicml.metrics.Metric` values the caller wants
(e.g. `epoch  12/400 | loss: 0.041234 | mae: 0.1523 | r2: 0.9812`). The core
library stays bare -- the core only supplies the stateful `Metric` objects; the
formatting/printing helper lives in the `basicml/visualize/` edge package
(Google-style docstrings). Retrofit `examples/train_linear.py` to use it.

## Requirement

- `basicml/visualize/progress.py`:
  - `format_metric_line(epoch, total, values: dict[str, float], prefix="") -> str`
    -- pure formatter, aligned columns.
  - `ProgressPrinter` -- holds a caller-supplied `dict[str, Metric]`;
    `.update(y_pred, y_true, loss)` accumulates a batch, `.end_epoch(epoch, total)`
    prints the line and resets the metrics; optional `every=N` for sparse output.
  - both re-exported from `basicml/visualize/__init__.py`.
- `examples/train_linear.py` prints loss + MAE/RMSE/R2 each epoch via
  `ProgressPrinter`.
- `pyrefly check` clean for the new/changed files; the example runs end-to-end.
