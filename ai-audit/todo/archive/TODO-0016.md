## Description

Add a model diagnostic that checks the four error rungs from Ng's bias/variance
recipe -- train error, train-dev error, dev error, test error (plus a
human-level baseline) -- and names the dominant gap (avoidable bias, variance,
data mismatch, dev overfitting). Lives as a reusable helper in a new
library-edge package `basicml/diagnostics/` (Google-style docstrings) plus a
runnable example that exercises it on the optimizer-comparison MLP.

## Requirement

- `basicml/diagnostics/error_ladder.py`: `ErrorLadder` dataclass (five rungs +
  four gap properties + `gaps()` / `diagnosis()` / `summary()`),
  `classification_error(model, X, y)` scorer, `error_ladder(...)` builder that
  evaluates a trained model on all splits.
- `BasicML/examples/train_error_diagnostic.py`: trains the MLP on a clean
  make_moons slice, evaluates against a deliberately noise-shifted dev/test
  distribution, prints `ladder.summary()`.
- `pyrefly check` clean for the new files; example runs end-to-end.
