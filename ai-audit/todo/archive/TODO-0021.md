## Description

Add a LeNet-shaped variant of the trained-CNN feature-map animation
(TODO-0020): same fixed-sample, record-per-epoch, animate-afterward idea,
but with a LeNet-5-inspired architecture instead of the small ad hoc CNN.

## Requirement

- New, separate demo file (existing `plot_dynamic_cnn_feature_maps.py` left
  untouched) so both remain runnable and comparable.
- "Modernized LeNet": keeps original LeNet-5 layer shapes (6 then 16 conv
  channels, 5x5 kernels, 120- then 84-unit FC layers before the 10-way
  output) but uses ReLU + MaxPool2D instead of the original Tanh + AvgPool,
  and skips the classic 28x28->32x32 zero-padding (two valid 5x5 convs end
  at 24x24 -> 4x4 instead of 28x28 -> 5x5).
- Same MNIST source (`sklearn.datasets.fetch_openml`, already a declared
  dependency from TODO-0020) and the same animated-over-training
  visualization style.
