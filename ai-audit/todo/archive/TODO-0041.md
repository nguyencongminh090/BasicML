## Description

AdvanceML's `nn`/`optim` C++ modules currently only cover the subset needed for the MNIST CNN example, while BasicML's Python equivalents are far broader. Bring AdvanceML up to feature parity with BasicML by implementing the missing pieces:

- **Loss**: `AbsoluteLoss`, `BinaryCrossEntropy` (BasicML has these plus `MSELoss`/`CrossEntropyLoss`, which AdvanceML already has).
- **Optimizer**: `Nesterov`, `Adagrad`, `Adadelta`, `RMSprop`, `Muon` (AdvanceML already has `SGD`, `Momentum`, `Adam`, `AdamW`).
- **Layer**: `GlobalAvgPool2D`, `GlobalMaxPool2D`, `BatchNorm` (1D, alongside existing `BatchNorm2D`), `Dropout`.
- **Activation**: `Tanh`, `Identity`, `PReLU`, `ELU`, `SELU`, `Softplus`, `Swish`, `Mish`, `Hardtanh`, `Hardsigmoid`.

Each new component must fit AdvanceML's autograd design (define-by-run graph, no manual per-layer `backward()`) and use the oneDNN backend interface where applicable, per `AdvanceML`'s architecture conventions in the root `CLAUDE.md`.

- [x] Every listed Loss/Optimizer/Layer/Activation exists as a class under `AdvanceML/include/advanceml/` (public header) with matching `AdvanceML/src/` implementation, mirroring the existing directory layout.
