## Description

Build a beginner-facing demo under `BasicML/demo/` that visualizes CNN
feature maps and receptive field growth, built on the `Conv2D` /
`MaxPool2D` / `ReLU` modules already added under `basicml/nn/` in
TODO-0018 — no new library module needed (confirmed with the user: reuse
the existing `basicml/nn` modules rather than self-contained demo
functions). No training required; illustrates structure only.

## Requirement

- Runnable end-to-end via `python BasicML/demo/plot_feature_maps_receptive_field.py`,
  numpy + matplotlib only, no training loop.
- Builds a small Conv2D/ReLU/MaxPool2D stack (3-4 conv layers, some with
  stride/pooling) over one synthetic image with clear edges/shapes.
- Plots a grid of feature maps per layer, labeled with layer index,
  spatial size, and channel count.
- Computes and prints/plots theoretical receptive field growth
  (`RF_l = RF_{l-1} + (k_l - 1) * jump_{l-1}`) for two variants built from
  the same layer stack: stride-1 (no downsampling) vs. the actual
  strided/pooled stack, showing linear vs. multiplicative growth.
- Computes the effective receptive field via a manual backward pass
  (one deepest-unit gradient set to 1, propagated through each layer's own
  `backward()`), plotted as a gradient-magnitude heatmap over the input
  image.
- Overlays the theoretical RF box and the effective RF heatmap on the same
  image so the gap between theory and practice is visible.
