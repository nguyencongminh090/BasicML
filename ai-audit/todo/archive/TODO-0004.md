## Description

Add inverted Dropout to `BasicML` as a parameterless `nn.Module` that sits in the forward
chain next to the activations. During training it samples a fresh binary keep-mask per
forward call and scales surviving activations by `1 / (1 - p)`; during evaluation it is a
plain passthrough. `backward()` reuses the cached mask and the same scale.

Dropout needs train/eval state, which the current architecture has no notion of, so this
TODO also introduces a `training` flag on `nn.Module` with `train()` / `eval()` toggles,
and `Sequential.train()` / `Sequential.eval()` that fan out to child modules.

Dropout is *not* a `regularization.Regularizer` — that ABC is parameter-space
(`penalty`/`grad` on a `Tensor`, applied in the optimizer). Dropout acts on activations
and has no parameters.

## Requirement

- `nn.Module`: `self.training: bool = True`; `train(mode: bool = True)` sets it and returns
  `self`; `eval()` calls `train(False)`. Default stays `True` so existing example/demo
  training loops are unaffected.
- `Sequential.train()` / `.eval()` set their own flag and call the same on every child in
  `self.layers`, returning `self`.
- New `basicml/nn/dropout.py` with `class Dropout(Module)`:
  - `__init__(self, p: float = 0.5)` — validate `0 <= p < 1`; store `p`.
  - `forward(X)`: if `not self.training` or `p == 0`, return `np.asarray(X)` unchanged and
    cache no mask. Otherwise sample `mask = (rng.random(x.shape) >= p) / (1 - p)`, cache it,
    return `x * mask`.
  - `backward(grad_output)`: return `grad_output * mask`; raise `RuntimeError` if called
    with no cached mask (mirrors the activation modules' guard), *unless* the last forward
    was in eval/`p==0` passthrough — in that case return `grad_output` unchanged.
  - `parameters()` inherited (empty).
  - Use a module-level `np.random.default_rng()` (or `np.random`), consistent with how
    `basicml/nn/linear.py` / `datasets` seed randomness — match the existing convention.
- Export `Dropout` from `basicml/nn/__init__.py` alongside the activations.
- `__repr__` showing `Dropout(p=...)` (Sequential's `__repr__` calls `repr(layer)`).
- `pyrefly check` clean; existing `examples/` + `demo/` scripts still run unchanged.
- Follow-up (separate TODO): an example demonstrating Dropout reducing the train/val gap,
  parallel to `examples/train_regularization.py`.
