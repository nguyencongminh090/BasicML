## Description

Fill in the `BatchNorm` layer stub (`basicml/nn/batchnorm.py`) as a proper
PyTorch-`BatchNorm1d`-style module: normalize each feature over the batch,
learnable affine `gamma`/`beta` exposed through `parameters()`, running
mean/variance buffers updated with momentum during training and used for
normalization under `eval()`. Backward is hand-derived like every other
layer (accumulates into `gamma.grad`/`beta.grad` with `+=`, returns the
upstream gradient).

## Requirement

- `BatchNorm(num_features, eps=1e-5, momentum=0.1, affine=True)` replacing
  the no-arg stub; core module stays bare (no comments, no docstrings).
- Training mode normalizes with batch statistics and updates the running
  buffers (unbiased variance for the buffer, PyTorch-style); `eval()` mode
  normalizes with the running buffers.
- `parameters()` returns `[gamma, beta]` when `affine`, else `[]`.
- Manual `backward` passes a numerical gradient check.
- Add `BatchNorm` cases to `examples/check_gradients.py` (standalone +
  stacked between `Linear` layers). No new demo.
