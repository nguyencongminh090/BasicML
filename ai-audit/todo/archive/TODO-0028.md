## Description

User asked to rewrite the LeNet-on-MNIST demo using AdamW only (dropping
the Muon comparison from `train_lenet_mnist.py`, whose confirming decayed
run was cancelled in the prior session -- TODO-0027) and to split it into a
main training file, a hyperparameter-tuning file, and a shared config file
connecting the two.

## Requirement

- New `BasicML/examples/lenet_config.py`: a single frozen `LeNetConfig`
  dataclass holding every hyperparameter (seed, image size, train/test
  sizes, conv channels, FC widths, epochs, batch size, lr, weight decay)
  plus a `DEFAULT_CONFIG` instance -- the one source of truth both other
  files build on.
- New `BasicML/examples/train_lenet_adamw.py`: the LeNet-shaped model
  (6/16 conv channels, 120/84 FC, same shape as `train_lenet_mnist.py`) and
  training loop, entirely parameterized by a `LeNetConfig` instead of
  module-level constants; AdamW only, no Muon. Exposes `run(cfg,
  show_plot)` returning per-epoch logs so the tuning script can read off
  results without parsing stdout, and a `verbose` flag on `train()` so a
  hyperparameter search doesn't flood stdout with per-epoch lines per
  candidate.
- New `BasicML/examples/tune_lenet_adamw.py`: grid search over
  `lr` x `weight_decay` (3x3 = 9 candidates) on a cheap proxy budget (4
  epochs, 4000/1000 train/test images, MNIST fetched once and shared across
  every trial), each candidate built via `dataclasses.replace()` on a base
  `LeNetConfig` and trained by calling straight into
  `train_lenet_adamw.build_model`/`train` -- the model/training loop exist
  in exactly one place. Ranks candidates by held-out test accuracy, then
  (by default) validates the winner with one full-budget run via
  `train_lenet_adamw.run()` so the final reported number is genuine, not
  the cheap-search proxy.
