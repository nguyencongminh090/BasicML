## Description

Add a 2-feature linear regression demo: a synthetic dataset where (x1, x2)
scatter around a parabola curve in the feature plane, with y as a noisy
linear combination of both features. Animate training the same way as
`plot_dynamic_linear.py`, adapted for a 2D weight vector.

## Requirement

- New dataset generator in `basicml/datasets/synthetic.py`, exported from
  `basicml/datasets/__init__.py`.
- New demo script under `BasicML/demo/` mirroring the 5-panel layout of
  `plot_dynamic_linear.py`, with panels 3/4/5 re-parameterized over
  `(w1, w2)` instead of `(w, b)`, and panel 1 adapted to a 3D scatter + fit
  plane since a single fit line no longer applies with 2 input features.
- Script runs end-to-end and the recovered optimizer minimum matches the
  closed-form least-squares optimum.
