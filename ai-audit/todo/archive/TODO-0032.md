## Description

Follow-up to [TODO-0031](TODO-0031.md) (autograd engine milestone 1, done): the autograd mechanism itself is proven, but AdvanceML currently has no reusable API layer — only free functions (`matmul`, `relu`, `mse_loss`) and one optimizer (`SGD`) with no shared base classes. Bring AdvanceML's component set up to the same completeness BasicML has (`Module`, layers, `Loss`, `Optimizer` abstractions), mirroring BasicML's architecture in C++ idiom rather than porting it line-for-line.

Target shape, parallel to `basicml/`:

- **`Module`** — abstract base with virtual `forward(Tensor)` and `parameters()` (default: empty), matching `basicml/nn/module.py`'s contract. Concrete layers subclass it: `Linear` (wraps `matmul` + bias-add, owns `w`/`b` as `requires_grad` `Tensor`s, Xavier/He init via `Tensor::random_uniform` or a new init helper), `ReLU`, and a `Sequential` container (owns a list of `Module`s, chains `forward`, aggregates `parameters()`).
- **`Loss`** — abstract base with `operator()(pred, target)` returning a scalar `Tensor` (so `.backward()` on the result still works through the same autograd graph — no separate backward method needed, unlike BasicML, since the graph already ties `Loss`'s output back to `pred`). Wrap the existing `mse_loss` free function as `MSELoss : Loss`; leave room for others (e.g. cross-entropy) as follow-ups.
- **`Optimizer`** — abstract base with `step()`/`zero_grad()` over a `vector<Tensor>` of parameters, matching `basicml/optim/optimizer.py`'s contract. Refactor the existing `SGD` to derive from it.
