## Description

Add an AlexNet-shaped variant of the trained-CNN feature-map animation
(same family as TODO-0020's custom CNN and TODO-0021's LeNet): same
fixed-sample, record-per-epoch, animate-afterward idea, with an
AlexNet-inspired architecture instead.

## Requirement

- New, separate demo file (existing `plot_dynamic_cnn_feature_maps.py` and
  `plot_dynamic_lenet_feature_maps.py` left untouched).
- AlexNet's original shape (5 conv layers, channel count grows then
  plateaus like 96->256->384->384->256, max-pooling only after conv1/conv2/
  conv5 — not after every conv, unlike LeNet, 2 big FC layers with Dropout,
  ReLU throughout) applied at scaled-down channel/FC widths sized for MNIST
  rather than AlexNet's original ImageNet-scale widths.
- Native 28x28 MNIST input (no upscaling), with 3x3/stride-1 convolutions
  instead of the original's 11x11/stride-4 first layer, since the original
  kernel/stride sizes would collapse a 28x28 image before conv2 even runs.
- Same MNIST source (`sklearn.datasets.fetch_openml`) and animated-over-
  training visualization style as the sibling demos.
