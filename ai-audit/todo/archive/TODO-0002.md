## Description

Add L1 / L2 / ElasticNet regularization to `BasicML`, wired into the optimizers as a
PyTorch-style penalty on the parameter gradient. Introduces a new `basicml/regularization.py`
module with a `Regularizer` ABC (`penalty()` for the scalar R(θ) used in logging/plots,
`grad()` for ∂R/∂θ added to `param.grad` inside `Optimizer.step()`). `SGD` and `Momentum`
take an optional `regularizer` through the `Optimizer` base class. Learning-motivated:
follow-up work adds examples comparing L1 vs L2.

## Requirement

- `basicml/regularization.py`: `Regularizer` ABC + `L1`, `L2`, `ElasticNet`, coefficient named `lambda_`.
- `Optimizer` base class carries `regularizer: Optional[Regularizer] = None`.
- `SGD.step()` / `Momentum.step()` add `regularizer.grad(param)` to the gradient before the
  update rule (Momentum: before the velocity update — PyTorch-aligned).
- Penalty applies to all parameters incl. bias (PyTorch default); reported loss is data-only.
- `pyrefly check` clean; existing `examples/` + `demo/` scripts still run.
- Follow-up (separate TODO): example(s) comparing L1 vs L2 training.
