## Description

Add an evaluation-metrics module `basicml/metrics.py` — a stateful `Metric` ABC
modelled on the repo's own `Loss`/`Optimizer`/`Regularizer` abstractions and on
torchmetrics' `update()` / `compute()` / `reset()` contract (`__call__` =
update + compute on one batch, state accumulates across mini-batches). Kept bare
(no comments, no docstrings) like the rest of the core, `RuntimeError` guards for
compute-before-update.

Coverage:
- Classification via a shared `ConfusionMatrix` (binary threshold + N-class):
  `ConfusionMatrix`, `Accuracy`, `Precision`, `Recall`, `F1Score` — the last
  three derive from a `ConfusionMatrix` (own or injected for sharing), with
  `average` in `binary | macro | micro | weighted | None`.
- Ranking / curves (binary scores): `RocCurve`, `AUROC`, `PrecisionRecallCurve`,
  `AveragePrecision`, sharing a `_RankingMetric` base that pools (score, target).
- Regression: `MeanSquaredError`, `RootMeanSquaredError`, `MeanAbsoluteError`,
  `R2Score`, sharing a streaming `_RegressionMetric` accumulator.

## Requirement

- `pyrefly check` introduces no new errors.
- Values validated against hand-computed / sklearn-equivalent reference cases
  (binary + multiclass P/R/F1 with every `average`, ROC-AUC, average precision,
  R2) — there is no test suite, so a throwaway check script is run and its
  output recorded in the fix-log.
- Core style honoured: no comments, no docstrings, column-aligned imports,
  `RuntimeError` guards.
