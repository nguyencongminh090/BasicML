## Description

Give the `nn` layer classes readable "represent text" — `__repr__` (and, where
useful, other dunders) — so printing a model or a layer shows its type and
configured hyper-parameters instead of a bare `<object at 0x...>`. `BatchNorm`,
`Dropout` and `Sequential` already had `__repr__`; the base `Module`, `Linear`
and the parametrized activations did not.

## Requirement

- `repr(layer)` returns `ClassName(<config>)` for every `Module` subclass.
- `Sequential` repr lists its children (already did) and it supports
  `len()` / indexing / iteration over its layers.
- Core-module style preserved: no comments, no docstrings, no return annotations
  on the dunders (matches the existing `__repr__` in `dropout.py` /
  `sequential.py`).
- `pyrefly check` error count unchanged.
