## Description

Add a `BasicML/demo/` animation that makes the **vanishing gradient** visible:
train two deep MLPs of identical shape that differ only in hidden activation +
init — Sigmoid + Xavier (vanishing) vs ReLU + He (healthy) — and animate, per
epoch, the per-layer gradient magnitude, the per-layer `mean f'(z)` (with its
cross-layer product), plus loss / val-accuracy and the neuron graph. Adapted
from `plot_dynamic_mlp_graph.py`.

## Requirement

- One runnable file `BasicML/demo/plot_dynamic_vanishing_gradient.py`, run
  directly with `python`.
- Two models, same `[n_features, WIDTH×DEPTH, 1]` shape, `DEPTH ≥ 10`; only
  `activation` + `init_type` differ. Sigmoid output on both.
- Uses existing primitives only (`Sequential`, `Linear`, `Sigmoid`/`ReLU`/`Tanh`,
  `Momentum`); no changes to `basicml/`.
- Panels: neuron graph, weight/gradient heatmap row (toggle `g`/`w`), BCE loss,
  val accuracy, `RMS(∂L/∂w)` vs depth (log), `mean f'(z)` vs depth + product.
- The Sigmoid model should visibly fail to learn (loss ~flat, val acc at
  majority-class) while gradient magnitude sits orders of magnitude below the
  ReLU model and `Π f'(z)` collapses.
- Repo conventions: Vietnamese comments, English identifiers, aligned imports.
