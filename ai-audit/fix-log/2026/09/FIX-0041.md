## Prompt

Follow-up to the trained-CNN feature-map demo (TODO-0020): "Apply LeNet for
demo?"

## Action

- Asked and got explicit answers on the two open design points: (a)
  "modernized LeNet" (ReLU + `MaxPool2D` instead of the original Tanh +
  AvgPool, and no 28x28->32x32 zero-padding) rather than a historically
  exact LeNet-5, and (b) a new, separate demo file rather than replacing the
  model in `plot_dynamic_cnn_feature_maps.py`.
- Added `BasicML/demo/plot_dynamic_lenet_feature_maps.py`, adapted from the
  TODO-0020 demo's structure (`load_mnist_subset`/`train_and_record`/
  `animate`) with a LeNet-shaped `build_model()`/`forward()`/`backward()`:
  `Conv2D(1,6,k5,p0)->ReLU->MaxPool2D(2)` -> `Conv2D(6,16,k5,p0)->ReLU->
  MaxPool2D(2)` -> `Flatten->Linear(256,120)->ReLU->Linear(120,84)->ReLU->
  Linear(84,10)->Softmax`, keeping LeNet-5's original 6/16 conv-channel and
  120/84 FC sizes. On 28x28 MNIST (no 32x32 pad) the two valid 5x5 convs
  land at 24x24 and 8x8 instead of the original's 28x28/5x5, so the
  flattened feature count is 16*4*4=256, not LeNet-5's 16*5*5=400.
- `pyrefly check` clean for the new file. Smoke-tested with
  `N_TRAIN=400, EPOCHS=4` (loss 2.14->0.34, acc 0.26->0.87, ~0.9s), then ran
  the full configured settings (`N_TRAIN=3000, EPOCHS=15`) headlessly end to
  end (~45s train time, acc reached ~0.99) and rendered frames at epochs
  1/8/15 to visually confirm the 6-channel conv1 / 16-channel conv2 grid
  (with the 2 empty conv1 grid columns and 8 hidden conv2 channels handled
  correctly by the per-row `conv1_shown`/`conv2_shown` counts).

## Decision

- Kept the same flat `dict[str, Module]` + manual-chain pattern as
  TODO-0020's demo (`build_model`/`forward`/`backward`/`parameters`) rather
  than introducing a shared helper between the two demo files -- the two
  models differ enough (extra FC layer, different conv/pool sizes, different
  number of feature-map rows worth tracking) that a shared abstraction would
  have added indirection for two ~250-line scripts, and this repo's demo
  files are meant to be read start-to-end independently.
- Left `plot_dynamic_cnn_feature_maps.py` (TODO-0020) untouched per the
  user's explicit choice, so the two architectures stay directly comparable
  side by side.

## Conclusion

Fixed/working. LeNet-shaped model trains cleanly on real MNIST to ~99%
train accuracy in 15 epochs; feature-map animation renders correctly for
both conv layers (6ch 24x24, 16ch 8x8, first 8 of 16 shown). Verification
performed: `pyrefly check`, one short smoke run, one full headless run with
saved frames inspected at three epochs. No automated test suite exists in
this repo to add a permanent regression test to.
