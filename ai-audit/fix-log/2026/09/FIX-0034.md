## Decision

- Generic `Module.__repr__` instead of one per activation — the no-arg
  activations have nothing to show but their class name, so a base default is
  DRY and each parametrized class overrides with just its own fields.
- No `__str__` — Python falls back to `__repr__`, which is the desired output.
- No comments / docstrings / return annotations on the dunders, matching the
  `__repr__` already in `dropout.py` / `sequential.py` (core-module style).
