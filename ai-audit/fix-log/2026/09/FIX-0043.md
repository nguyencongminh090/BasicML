## Prompt

Follow-up to the CNN (TODO-0020) and LeNet (TODO-0021) trained
feature-map demos: "Okay, add AlexNet".

## Action

- Asked and got explicit answers on the two open design points: (a)
  scaled-down conv/FC widths sized for MNIST rather than AlexNet's original
  ImageNet-scale widths (96/256/384/384/256 channels, FC 4096/4096), and (b)
  keep native 28x28 input (no upscaling).
- Added `BasicML/demo/plot_dynamic_alexnet_feature_maps.py`, same
  record-per-epoch/animate-afterward structure as the sibling demos, with an
  AlexNet-shaped `build_model()`/`forward()`/`backward()`:
  `Conv2D(1,32,k3,p1)->ReLU->MaxPool2D(2)` ->
  `Conv2D(32,64,k3,p1)->ReLU->MaxPool2D(2)` ->
  `Conv2D(64,96,k3,p1)->ReLU` -> `Conv2D(96,96,k3,p1)->ReLU` ->
  `Conv2D(96,64,k3,p1)->ReLU->MaxPool2D(2)` -> `Flatten->Linear(576,512)->
  ReLU->Dropout(0.3)->Linear(512,256)->ReLU->Dropout(0.3)->Linear(256,10)->
  Softmax`. Preserves AlexNet's defining structural traits: 5 conv layers
  whose channel count grows then plateaus (32/64/96/96/64, echoing the
  original's 96/256/384/384/256), pooling only after conv1/conv2/conv5 (not
  after every conv, unlike the LeNet demo), 2 Dropout-regularized FC layers,
  ReLU throughout. Local Response Normalization (the original's other
  novelty) intentionally skipped -- no `basicml.nn` implementation exists,
  and it's since been shown to add little over what Dropout/BatchNorm
  already provide.
- Added `set_training(layers, mode)` helper (new vs. the sibling demos,
  needed because `Dropout` is the first layer in this family that reacts to
  `Module.training`) so the per-epoch snapshot forward pass runs in eval
  mode (deterministic prediction) while training minibatches run in train
  mode (Dropout active).
- `pyrefly check` clean. Smoke-tested with `N_TRAIN=300, EPOCHS=3`
  (19.3s/3 epochs) to confirm shapes and gradient flow, then tuned defaults
  for a tractable full run: this model (5 conv layers, two 512/256-wide FC
  layers) is markedly heavier than the LeNet/custom-CNN siblings in
  pure-numpy tap-loop `Conv2D`/`Linear`, so `N_TRAIN`/`EPOCHS` were reduced
  to 1200/10 (from the siblings' 3000/15) and `LEARN_RATE`/`DROPOUT_P`
  adjusted (0.002/0.3, from 0.01/0.5) for faster convergence on a smaller
  set. Ran the tuned full configuration twice (once inline, once
  backgrounded) end to end: ~281s train time both times (deterministic,
  seeded), loss 2.24->0.066, train accuracy ->97.75%. Rendered frames at
  epochs 1/5/10 from the recorded snapshots and inspected them.

## Decision

- Reduced `N_TRAIN`/`EPOCHS`/tuned `LEARN_RATE`/`DROPOUT_P` rather than
  keeping the sibling demos' settings, once the smoke test showed this
  model's per-epoch cost is roughly 5-6x the LeNet demo's (more conv layers,
  larger channel counts, two large FC layers) -- kept full-run time to
  ~4-5 min rather than the ~16 min a literal settings-copy would have taken,
  while still reaching >97% train accuracy.
- Reused the same flat `dict[str, Module]` + manual-chain pattern as the two
  sibling demos (documented already in FIX-0041's Decision) rather than a
  shared base -- consistent with keeping each demo file independently
  readable.

## Conclusion

Fixed/working. AlexNet-shaped model trains to ~98% train accuracy on 1200
MNIST samples in 10 epochs (~4.7 min); feature-map animation renders
correctly for all three tracked conv layers (32ch@28x28, 96ch@7x7,
64ch@7x7, 8 of each shown). Verification performed: `pyrefly check`, one
short smoke run to validate shapes/gradient flow, one full run (inline) plus
one full run (background task) both producing identical loss/accuracy
curves (deterministic under the fixed seed), frames inspected at three
epochs. No automated test suite exists in this repo to add a permanent
regression test to.
