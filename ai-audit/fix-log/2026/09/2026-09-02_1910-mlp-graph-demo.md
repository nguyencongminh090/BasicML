## Prompt

Via `/prompt-architect` (RISEN): "write demo about network graph of a Deep MLP —
display graph of neurons/weights within layers, run a training loop and animate
the weight learning, apply Dropout + regularization, run a large multi-layer
model." Clarified: large architecture, any real dataset, Dropout/reg as
toggles + side-by-side comparison, live matplotlib `FuncAnimation` window.

## Action

- Added `BasicML/demo/plot_dynamic_mlp_graph.py` (new file, ~300 lines).
  - `load_data()` — sklearn `load_breast_cancer` (30 feat) with guarded import,
    `basicml.make_moons` fallback; 70/30 split, standardized on train stats.
  - `build_model(n_features, use_dropout)` — `Sequential` of
    `Linear(he)+ReLU (+Dropout(p=0.30))` × 4 hidden `[64,64,64,32]` then
    `Linear(xavier)+Sigmoid`.
  - `train_and_record()` — full-batch manual loop
    (`forward → loss.backward() → model.backward → optimizer.step → zero_grad`),
    `Momentum(regularizer=L2)` for the reg model, `train()/eval()` toggled so
    Dropout is off during evaluation; snapshots weights + train-loss +
    train/val accuracy + Σ L2 penalty every `RECORD_EVERY=8` epochs.
  - `draw_graph()` — sparse node-edge graph, layers subsampled to
    `MAX_NODES=12`, `TOPK_EDGES=40` strongest edges per layer pair,
    colour = weight sign, width/alpha ∝ |w| (global max).
  - `animate()` — gridspec: two graph columns (plain vs Dropout+L2), a row of
    per-layer weight heatmaps (`RdBu_r`, symmetric vmin/vmax) under each, and
    shared BCE-loss + val-accuracy curve panels; running epoch / val acc /
    R(θ) in the suptitle. `FuncAnimation(blit=False, repeat=False)`.
  - Two models built under the same `np.random.seed(SEED)` → identical init.
- No changes to `basicml/` — all primitives already existed.

## Decision

Large hidden layers (64) make a literal per-edge neuron graph unreadable, so the
weight matrices are shown primarily as per-layer heatmaps, with the node-edge
graph kept as a subsampled top-k view for intuition. Side-by-side same-init
comparison chosen (per user) so the regularizing effect on the weights is
directly visible. Full-batch training keeps the animation deterministic and the
per-frame cost low.
