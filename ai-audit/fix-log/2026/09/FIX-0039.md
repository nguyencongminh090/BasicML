## Prompt

Build a demo, for a beginner-level learner, that visualizes feature maps and
receptive field growth in CNNs inside this repository, using this repo's
manual-backward `basicml` style. Before writing code, ask whether the conv
layer should be a new reusable `Conv2D` under `basicml/nn/` or self-contained
in the demo script. Then: (1) forward convolution with kernel/stride/pooling
support, (2) plot a feature-map grid per layer, (3) compute/print theoretical
receptive field growth for a stride-1 vs. strided/pooled variant of the same
layer stack, (4) compute the effective receptive field via a manual backward
pass, (5) overlay theoretical vs. effective RF on the same image.

## Decision

- Reused `basicml.nn.Conv2D`/`MaxPool2D`/`ReLU` per the user's explicit
  choice, rather than duplicating conv/pool math in the demo file --
  exercises the real, already-gradient-checked library code and avoids
  drift between two conv implementations.
- Seeding the effective-RF backward pass at a fixed `(row=2, col=2, channel
  0)` deepest unit initially produced an all-zero heatmap: with untrained
  He-initialized weights, channel 0 at that position was a dead ReLU
  (`0.0` activation), and `MaxPool2D.backward`/`ReLU.backward` correctly
  propagate zero gradient through a dead unit's whole path. Switched to
  picking, at the fixed center position, the channel with the largest
  forward activation (`argmax` over channels) -- still one single unit's
  gradient, but guaranteed non-dead for whatever random seed is in play.
- Kept the RF-growth "variant A" as the *same* `LAYER_SPECS`/kernel-size
  list with every stride forced to 1 (pooling layers included, just not
  downsampling), rather than removing the pooling layers structurally --
  matches the task's "built from the same layer stack" requirement and
  isolates stride/pooling as the sole variable driving the RF gap.
