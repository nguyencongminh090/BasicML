## Prompt

User: "Help me add BatchNorm layer." A no-arg `BatchNorm(Module)` stub with
`forward`/`backward` as `...` already existed at `basicml/nn/batchnorm.py`.

## Action

- `basicml/nn/batchnorm.py`: implemented the layer.
  - `__init__(num_features, eps=1e-5, momentum=0.1, affine=True)`; validates
    `num_features > 0`; `gamma` (ones) / `beta` (zeros) as `(1, C)`
    `requires_grad` Tensors when `affine`, else `None`; `running_mean`
    (zeros) / `running_var` (ones) plain-ndarray buffers.
  - `forward`: rejects non-2-D / wrong-width input. Training: normalize with
    batch mean + biased batch variance, update `running_mean` /
    `running_var` (unbiased variance, PyTorch-style) via `momentum`. Eval:
    normalize with the running buffers. Caches `x_centered`, `std_inv`,
    `x_hat`.
  - `backward`: guards `RuntimeError("backward called before forward pass")`;
    accumulates `gamma.grad += sum(g * x_hat)`, `beta.grad += sum(g)`;
    returns the standard BN input gradient in training mode, `g * gamma *
    std_inv` in eval mode.
  - `parameters()` → `[gamma, beta]` when affine else `[]`; `__repr__` added.
  - Removed the stub's redundant `train` / `eval` / `__call__` overrides
    (inherited from `Module`) and the unused `init` import. Core module kept
    bare (no comments / docstrings) per CLAUDE.md.
- `BasicML/examples/check_gradients.py`: added `BatchNorm` import, a
  standalone `("BatchNorm", BatchNorm(IN_FEATURES))` case, and a stacked
  `("MLP batchnorm", Sequential(Linear(4,6,bias=False), BatchNorm(6),
  Tanh(), Linear(6,3,bias=False), BatchNorm(3), Linear(3,2)))` case;
  extended the `build_cases` docstring and noted why the pre-BN `Linear`
  layers are `bias=False`.
- Verified: `python3.13 BasicML/examples/check_gradients.py` → all 6 cases
  OK, exit 0 (BatchNorm max rel err 1.0e-9, MLP batchnorm 2.9e-8).
  `pyrefly check` → 12 errors, all pre-existing in unrelated files
  (`examples/ref_code.py` etc.); none in the changed files. BN `gamma`,
  `beta`, and `dx` gradients also checked against numeric Jacobians for
  random upstream gradients (rel err ~1e-10).

## Decision

- Full PyTorch-`BatchNorm1d` behavior (affine params + running buffers +
  train/eval switch) per the user's AskUserQuestion answers, over a
  normalization-only or buffer-less variant.
- Running-variance buffer uses the unbiased estimate to match PyTorch;
  normalization uses the biased variance (standard BN).
- Stacked gradient-check case uses `bias=False` on the pre-BN `Linear`
  layers: a bias before BN has an identically-zero gradient, which the
  finite-difference check would otherwise flag as spurious round-off
  (`relative_error`'s `1e-8` denominator floor turns 0-vs-1e-10 into ~1e-2).
- No new demo, no README edit (README's layer table was already left
  non-exhaustive after TODO-0008), and no `nn/__init__.py` change (empty in
  this repo — layers are imported by module path).
