## Prompt

"Do TODO-0018" -- add convolutional-network building blocks to `basicml/nn/`
in the existing manual-backward style: `Conv2D`, pooling layers, `Flatten`, a
composite `CNNModel`, plus an end-to-end example on a synthetic image dataset.
Design agreed 2026-09-11 (see instructions/TODO-0018.md): vectorized tap-loop
conv, all four pooling variants, PyTorch-like conv API, `groups=1` only.

## Action

- `basicml/nn/init.py`: generalized `_fan_in_out` -- for >2D weight shapes
  (conv `(out_ch, in_ch, kH, kW)`) fan_in/out now multiply by the receptive
  field `kH*kW`, matching PyTorch. 2D (Linear) branch unchanged.
- New `basicml/nn/conv.py` -- `Conv2D(in_channels, out_channels, kernel_size,
  stride=1, padding=0, dilation=1, init_type='he', bias=True, groups=1)`.
  `_pair()` helper for int-or-`(h,w)` args; `groups != 1` raises. Weight
  `(out_ch, in_ch, kH, kW)`, bias `(out_ch,)`, both `requires_grad=True`.
  forward: pad input, loop the `kH*kW` kernel taps only, each tap a
  strided/dilated slice with `np.einsum('nihw,oi->nohw', ...)` accumulate over
  `(N, out_ch, H_out, W_out)`; caches the padded input. backward: mirrors the
  tap loop, `+=` into `w.grad`/`b.grad`, scatter-adds into a padded `dx` buffer
  via the same strided slices, then un-pads.
- New `basicml/nn/pool.py` -- `_WindowPool2D` base (shared output-size / tap
  slicing), `MaxPool2D` (per-output argmax over taps via strict `>`, backward
  routes grad to the winner only), `AvgPool2D` (spreads `grad / (pH*pW)`),
  `GlobalAvgPool2D` / `GlobalMaxPool2D` (reduce each channel to `(N, C, 1, 1)`;
  backward broadcasts / scatters). `stride` defaults to `kernel_size`.
- New `basicml/nn/flatten.py` -- `Flatten` `(N, C, H, W) -> (N, C*H*W)`,
  caches input shape, backward reshapes back.
- New `basicml/nn/models.py` -- `CNNModel(input_shape, num_classes=1,
  conv_channels=8, kernel_size=3, pool_size=2, init_type='he')`: `Conv2D` (same
  padding) `-> ReLU -> MaxPool2D -> Flatten -> Linear -> Sigmoid`, backward
  chains each sub-layer's `backward` in reverse explicitly; `parameters()` =
  conv + linear params. Requires H/W divisible by `pool_size`.
- `basicml/datasets/synthetic.py` -- new `make_blob_images(n_samples=240,
  size=12, blob_sigma=2.0, noise=0.15, random_state=None)`: single-channel
  images with one Gaussian blob whose quadrant (top-left vs bottom-right) sets
  the binary label; Google-style docstring. Re-exported from
  `datasets/__init__.py`.
- New `BasicML/examples/train_cnn.py` -- trains `CNNModel` on
  `make_blob_images` with `BinaryCrossEntropy` + `Adam` over `iter_minibatches`,
  drives `loss.backward() -> model.backward(grad)`, reports per-epoch loss +
  `Accuracy` via `ProgressPrinter`, prints validation accuracy, optional
  matplotlib montage of predictions.
- Core-module style kept: zero comments/docstrings in `conv.py` / `pool.py` /
  `flatten.py` / `models.py`, column-aligned imports, `RuntimeError("backward
  called before forward pass")` guards.

## Decision

- Conv fan-in fix lives in `init.py` (general, PyTorch-matching) rather than as
  bespoke std math inside `Conv2D` -- keeps the layer bare.
- `CNNModel` in a new `nn/models.py` with an explicit reverse `backward` chain,
  per the TODO (not a generic `Sequential` loop) -- it is the teaching pattern
  for composite models. CLAUDE.md's stale reference to a
  `models.LogisticRegressionModel` was left alone (out of scope).
- `GlobalAvg/MaxPool2D` output `(N, C, 1, 1)` so they compose uniformly with
  `Flatten`.
- `AvgPool2D` uses count-include-pad semantics (divides by full `pH*pW`),
  matching PyTorch's default.
- Example uses the strong quadrant signal, so it hits 100% train/val accuracy
  quickly -- kept simple as a "gradients converge" check rather than a hard
  task; `noise=0.4` / `blob_sigma=1.3` give a visible loss descent.
