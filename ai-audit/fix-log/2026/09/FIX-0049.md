## Prompt

"Write again demo with lenet use AdamW optimizer. You can divide -> main
file & tuning (hyper tuning) files and connect via a config."

## Action

- New `BasicML/examples/lenet_config.py`: frozen `LeNetConfig` dataclass
  (seed, image size, train/test sizes, conv channels, FC widths, epochs,
  batch size, lr, weight decay) + `DEFAULT_CONFIG`.
- New `BasicML/examples/train_lenet_adamw.py`: the same LeNet-5-shaped
  model as `train_lenet_mnist.py` (6/16 conv channels, 120/84 FC), AdamW
  only (no Muon), fully parameterized by a `LeNetConfig` instead of
  module-level constants. Exposes `run(cfg, show_plot)` returning per-epoch
  logs, and a `train(..., verbose=...)` flag to silence per-epoch printing.
- New `BasicML/examples/tune_lenet_adamw.py`: grid search over `lr` (3
  choices) x `weight_decay` (3 choices) = 9 candidates on a cheap proxy
  budget (4 epochs, 4000/1000 train/test images, MNIST fetched once and
  shared across every trial via `dataclasses.replace()` on a base config),
  ranks by held-out test accuracy, then by default retrains the winner
  once at the full budget via `train_lenet_adamw.run()`.
- `pyrefly check`: initial `from lenet_config import ...` / `from
  train_lenet_adamw import ...` failed (`Cannot find module`) since
  pyrefly's search root is `BasicML/`, not `BasicML/examples/`. Fixed by
  importing as `examples.lenet_config` / `examples.train_lenet_adamw`
  (works at runtime too -- `sys.path` already carries the `BasicML/`
  directory, and `examples/` needs no `__init__.py` as a namespace
  package). `pyrefly check` clean afterward for all three files.
- Smoke-tested `train_lenet_adamw.run()` directly (`n_train=300,
  n_test=100, epochs=2`): ran cleanly, accuracy rose epoch-over-epoch.
  Smoke-tested `tune_lenet_adamw.main()` with a monkey-patched tiny grid
  (2 lr values, 1 weight_decay, 1 epoch, 200/80 images, patched `run()` to
  keep the final-validation step equally cheap): ranking printed
  correctly, best candidate selected, final-validation run executed.

## Decision

- Dropped Muon from this rewrite entirely rather than parameterizing the
  optimizer choice too -- the user's instruction was specifically "use
  AdamW optimizer", and TODO-0026 already showed AdamW winning decisively
  against Muon on this exact architecture. `train_lenet_mnist.py` (the
  AdamW-vs-Muon comparison) is left in place unchanged; this is a new,
  separate script, not a replacement.
- Kept the config as one frozen dataclass rather than a YAML/JSON file --
  no existing script in this repo reads external config files, and a
  dataclass gives static typing/IDE support that a raw dict or file
  wouldn't, while still fully satisfying "connect via a config" (both
  `train_lenet_adamw.py` and `tune_lenet_adamw.py` import the same
  `LeNetConfig` and never duplicate a hyperparameter as a second literal).
- Tuning searches only `lr`/`weight_decay` (not conv channels/FC widths)
  to keep the grid small (9 candidates) and the search budget cheap (4
  epochs, ~4000 images) -- architecture search was not requested and
  would multiply the grid size for a much smaller expected payoff than
  optimizer hyperparameters.

## Conclusion

Three new files, `pyrefly check` clean, both scripts smoke-tested
end-to-end and confirmed to actually train and report results. Neither
the real 9-candidate grid search nor a full-budget (15000/2500, 15-epoch)
run was executed in this session -- that takes real wall-clock time and
wasn't requested; `tune_lenet_adamw.py`/`train_lenet_adamw.py` are ready
to run on demand. No automated test suite exists in this repo to add a
permanent regression test to.
