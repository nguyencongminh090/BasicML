  - `error_ladder.py` — frozen `ErrorLadder` dataclass (rungs `human`, `train`,

## Decision

- Diagnostic takes already-trained models and pre-split data rather than owning
  the training loop — keeps single-responsibility and lets any `Module` /
  `error_fn` plug in (dependency inversion).
- `error_fn` is pluggable so the same ladder works for regression (pass an
  MSE-style scorer) without branching inside `ErrorLadder`.
- Example deliberately shifts the dev/test noise level so the ladder produces a
  non-trivial, teachable verdict (data mismatch) rather than four near-equal
  rungs.
- `dataclass(frozen=True)` — first use in `basicml/`, but the edge packages
  already allow richer style than the bare core; an immutable value object with
  named gap properties reads better than a dict.
