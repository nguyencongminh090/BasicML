## 2026-09-03 16:20

**Discussed:** User wants a demo showing how the gradient direction changes
between mini-batches vs a stable full-batch (BatchGD) gradient, as motivation for
Momentum ("I need gradient to be stable"). Asked two design questions:
- Visualization → "Gradient fan on cost contour" (bold full-batch arrow + thin
  fan of per-batch arrows from the same frozen point, over the MSE contour, plus
  a per-batch angle bar chart).
- Optimizers → "SGD vs Momentum on mini-batch" (trace both paths).

**Decision:**
- New `BasicML/demo/plot_dynamic_minibatch_gradient.py`. Synthetic
  `y = 2.5x + 4 + N(0, 2.5)`, N=256, batch_size=32 → 8 batches (`data.csv` is
  only 9 rows, too small).
- Per epoch: freeze the SGD path point, compute the full-batch gradient and each
  mini-batch gradient *there* (no stepping) via a local `mse_gradient` helper
  matching `MSELoss` (cost `1/(2n)Σ`). Record unit descent dirs + per-batch angle
  to the full-batch direction.
- Both optimizers get the identical `iter_minibatches` schedule each epoch.
  Momentum lr scaled by `(1 - momentum)` so it isn't just a 10× step.
- 4 panels: gradient fan on contour + both paths; current fit; full-batch
  learning curves; per-batch angle bars.
- Tried adding a green "Momentum running-average step" arrow — removed it: near
  convergence the velocity is stale noise and pointed away from the min,
  misleading for teaching.

**Verification:** `pyrefly check` clean for the new file (pre-existing 11 errors
elsewhere untouched); rendered frames headless — early epochs fan spread ~20°
(batches agree), later epochs ~150° (batches disagree, full-batch grad tiny).
