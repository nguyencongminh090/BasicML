# TODO-0034 — AdvanceML umbrella: component-library parity with BasicML

## 2026-09-13

User's assessment (after TODO-0032/0033 landed the Module/Loss/Optimizer architecture): the *architecture* is in place but the *component library* is still thin compared to BasicML (1 activation, 1 loss, 1 optimizer, no CNN layers, no datasets/metrics helpers). Asked for one big TODO to track completing it.

Filed as an **umbrella TODO**, `status: open`, deliberately not started this session — it's explicitly too large for one sitting. Six areas identified, in landing-priority order:

1. CNN layers (`Conv2D`, pooling, `Flatten`, `BatchNorm2D`) via oneDNN conv/pooling primitives — the actual original motivation for AdvanceML.
2. More activations (Sigmoid, LeakyReLU, GELU, Softmax at minimum).
3. More losses (`CrossEntropyLoss`, needs Softmax from #2).
4. More optimizers (Momentum, Adam/AdamW at minimum; Muon as stretch).
5. Datasets/metrics utilities (a C++ MNIST loader, an accuracy metric).
6. A runnable MNIST CNN example, analogous to `BasicML/examples/train_cnn_mnist.py` — the concrete proof of the CPU-throughput goal, including a rough perf comparison against BasicML's equivalent.

Each area is meant to become its own sub-TODO (with its own branch/tests/fix-log entry) as work actually begins, gated by the WIP cap same as TODO-0030-0033 were. This TODO (0034) itself stays open as the umbrella/tracking entry until all sub-areas are done or explicitly deferred.

No code changes this session — TODO-filing only.
