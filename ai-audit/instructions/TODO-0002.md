## 2026-09-02 — design + first review pass (assistant advised, user wrote all code)

**Discussed:**
- Where regularization belongs. Weighed three homes: optimizer (`weight_decay`),
  `Linear.backward`, loss-level. Cohesion/coupling analysis favoured the optimizer —
  it already owns "iterate params and mutate them", so no new coupling; `Linear`'s job is
  the affine layer's *local* gradient, not training policy.
- PyTorch alignment: `weight_decay` is L2-only, applied to *all* params (bias included)
  unless param groups are used; reported loss reflects data fit only. User chose PyTorch-aligned.
- Interface vs direct float. Chose a `Regularizer` Strategy interface (`penalty()` + `grad()`)
  over a bare float because the user wants to try L1 *and* L2 and build comparison examples —
  open/closed (new penalty = new class), and `penalty()` gives a scalar to plot.
- L1 gradient = `lambda_ * np.sign(param)` (subgradient, `sign(0)=0`); constant-magnitude push
  toward 0 → sparsity, vs L2's magnitude-proportional `lambda_ * param`.
- Naming: coefficient `lam` → `lambda_` (keeps λ notation visible). Method arg `w` → `param`
  (regularization hits bias too, so `w` was misleading; `param` matches the optimizer loop var).

**Decision:**
- New file `basicml/regularization.py` at top level (so `optim` need not import `nn`):
  `Regularizer(ABC)` with `penalty(param) -> float` and `grad(param) -> np.ndarray`;
  `L1`, `L2`, `ElasticNet`. Coefficient `lambda_`.
- `Optimizer.__init__` gains `regularizer: Optional[Regularizer] = None`.
- `SGD` / `Momentum` add `self.regularizer.grad(param)` into `grad` before the update
  (Momentum: before the velocity update).
- Penalty on all params incl. bias; do NOT use an `ndim` heuristic to exclude bias
  (bias here is 2D `(1, out_features)` so the heuristic fails) — use an explicit flag if ever needed.
- True L1 sparsity needs a proximal/soft-threshold step; the gradient-term form is the
  learning-repo choice — leave a comment.

**Review findings across iterations (all raised by assistant, fixed by user):**
1. `Momentum.__init__` didn't accept/forward `regularizer` — fixed (added param, `super().__init__`).
   All `Momentum(...)` callers use `momentum=` keyword, so the new arg order is safe.
2. `SGD` `regularizer` param lacked `= None` default → would break ~18 existing callers — fixed.
3. Type mismatch: call sites passed `param.data` (ndarray) to `grad(param: Tensor)` which
   does `param.data` — `ndarray.data` is a memoryview → silent breakage. Fixed by passing `param`.
