**Decision:**
- New edge package `basicml/diagnostics/` with Google-style docstrings.
  `error_ladder.py`: frozen `ErrorLadder` dataclass with the five rungs, four
  gap `@property`s, `gaps()`, `diagnosis()` (largest gap -> advice string),
  `summary()` (printable block). Module fns `classification_error` (1 - accuracy,
  puts model in eval mode) and `error_ladder(model, train, train_dev, dev, test,
  human_error=0.0, error_fn=classification_error)`.
- Example `BasicML/examples/train_error_diagnostic.py`: trains on make_moons at
  noise 0.15; train-dev from the same generator (different seed); dev/test from
  a noise-0.35 "target" distribution so data mismatch is the illustrative gap.
  Adam lr 0.01, 120 epochs, batch 32.
