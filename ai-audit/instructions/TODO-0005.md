## 2026-09-02 19:35

**Discussed:** User asked what represents weight values in the model and wants to
*see* vanishing gradient by visualization. Explained: weight = `Linear.w.data`
`(in, out)`; vanishing is a property of `∂L/∂w`, not of `w` itself. User chose to
extend the *same* file with: (1) per-layer `‖∂L/∂w‖` panel over epochs (log),
(2) heatmap toggle weight ↔ gradient, (3) per-hidden-layer mean(|ReLU act|) +
% dead units.

**Decision:**
- `train_and_record` now also snapshots, every `RECORD_EVERY` epochs: grad
  matrices `l.w.grad` and their Frobenius norms (read *before*
  `optimizer.zero_grad()`), plus ReLU activation mean-abs and %-zeros from an
  eval-mode forward on the train set. `weight_grad()` helper narrows the
  `Optional[np.ndarray]` grad for the type checker.
- Grad shown is the pure backprop gradient — the L2 term is added by the
  optimizer at `step()` and never enters `w.grad`, which is exactly what you want
  for observing vanishing.
- Layout → 4×2 gridspec; added `ax_grad` (log-y, one line per layer, plain solid
  / reg dashed, viridis by depth) and `ax_act` (grouped bars + %dead labels).
- Heatmap mode via `HEATMAP_MODE` constant + `key_press_event` handler
  (`g`=grad, `w`=weight); suptitle shows current mode.

**Next step:** Smoke-tested headless in both heatmap modes (frame PNG checked) —
all 4 rows populate, curves/bars/graph update. Still awaiting user OK to commit.
