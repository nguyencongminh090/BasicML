## 2026-09-11 — design agreed (TODO created; not yet implemented)

**Discussed:** User asked to implement a CNN — `Conv2D` and pooling layers.
Flagged as a topic switch from TODO-0017 (this session's branch); user then
answered four scoping questions.

**Decision:**
- Conv forward/backward: **vectorized slicing** — loop over the `kH*kW`
  kernel taps only, vectorized accumulate over `(N, out_ch, H_out, W_out)`;
  backward mirrors the tap loop, `+=` into `w.grad`/`b.grad`, scatter-add
  into a padded `dx` then un-pad.
- Pooling: **all of** `MaxPool2D`, `AvgPool2D`, `GlobalAvgPool2D`,
  `GlobalMaxPool2D`.
- Scope: **layers + `Flatten` + composite `CNNModel` + example script**.
- Conv API: **PyTorch-like** — `stride`, `padding`, `dilation` as
  `int` or `(h, w)` tuple; `groups=1` only, documented as a limitation.
- Files: `nn/conv.py`, `nn/pool.py`, `nn/flatten.py`, `CNNModel` in
  `nn/models.py`, `examples/train_cnn.py` (or `demo/`).
- Bare core-module style (no comments/docstrings, aligned imports, keep the
  `RuntimeError` backward guards).
