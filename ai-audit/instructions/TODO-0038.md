## 2026-09-17 (implementation, same session)

Read the existing AdvanceML architecture first (`tensor.hpp`, `module.hpp`,
`linear.hpp/cpp`, `ops.hpp/cpp`) — note there is no separate `Backend` interface
class yet (contrary to the umbrella's wording): oneDNN's `dnnl::engine`/`dnnl::stream`
are just static helpers inside `ops.cpp`'s anonymous namespace (`cpu_engine()`,
`cpu_stream()`), and every autograd op (`matmul`, `relu`, ...) is a free function in
`ops.hpp`/`ops.cpp` with a thin `nn::Module` wrapper class in `nn/`. Followed that
existing convention rather than introducing a new abstraction.

Implemented:
- `ops::conv2d(x, weight, bias, stride, padding)` — oneDNN `convolution_forward` /
  `convolution_backward_data` / `convolution_backward_weights`, symmetric
  stride/padding, `(N,C,H,W)`/`(out,in,kh,kw)` layout (`nchw`/`oihw`).
- `ops::max_pool2d` / `ops::avg_pool2d` — oneDNN `pooling_forward`/`pooling_backward`
  (`pooling_max` with workspace for argmax routing; `pooling_avg_exclude_padding`,
  no workspace needed).
- `ops::flatten` — pure reshape `(N, ...) -> (N, prod(...))`, no oneDNN involved.
- `ops::batch_norm2d` — hand-written (no oneDNN primitive), per-channel normalize
  over `N,H,W`; takes `running_mean`/`running_var` by mutable `std::vector<float>&`
  reference since they're buffers, not autograd leaves. PyTorch-style momentum
  convention (`running = (1-momentum)*running + momentum*batch`). Training-mode
  backward accounts for `mean`/`var` depending on `x`; eval-mode backward treats
  them as constants.
- `nn::Conv2D`, `nn::MaxPool2D`, `nn::AvgPool2D`, `nn::Flatten`, `nn::BatchNorm2D`
  module wrappers, matching `Linear`'s pattern (Conv2D's weight init reuses
  Linear's Xavier-uniform formula with `fan_in = in_channels*k*k`,
  `fan_out = out_channels*k*k`). `BatchNorm2D` adds `train()`/`eval()` mode toggles
  (not part of the `Module` base — kept local since no other layer needs it yet).

Added `AdvanceML/tests/cnn_test.cpp` (9 new Catch2 cases): conv2d forward

BatchNorm2D zero-mean/unit-variance check + gradient check (training mode) +
eval-mode determinism check, and an end-to-end
Conv2D/ReLU/MaxPool2D/Flatten/Linear `Sequential` training test.
