**Decision:**
- New file `BasicML/demo/plot_dynamic_vanishing_gradient.py`, adapted (copied +
  trimmed) from `plot_dynamic_mlp_graph.py`. No `basicml/` changes.
- Side-by-side, same shape `30 → 12×24 → 1`, differ only in activation+init:
  `sigmoid + xavier` (left, red) vs `relu + he` (right, blue). Sigmoid output
  on both. No dropout / no L2 — keeps the gradient signal clean.
- Panels: neuron graph; heatmap row of 6 sampled Linear layers (weight ↔
  gradient toggle via `g`/`w` key, default `grad`), each titled with its norm;
  BCE loss; val accuracy; **`RMS(∂L/∂w)` vs depth** at the current epoch (log y —
  RMS not Frobenius so differently-sized layers compare fairly); **`mean f'(z)`
  vs depth** with the cross-layer product `Π f'(z)` in the legend + a 0.25
  reference line (sigmoid' max).
- `act_derivative_mean` reconstructs `f'(z)` from each activation's cached `.out`
  (sigmoid `o(1-o)`, tanh `1-o²`, relu `o>0`).

**Result (400-epoch smoke run):** sigmoid model loss stuck ~0.65, val acc 60.2%
(= majority class, never learns); relu model loss→0, val acc 98.2%. Gradient RMS:
sigmoid ~1e-9 across all layers vs relu ~2e-6 (~1000× gap); `Π f'(z)` sigmoid
≈ 2.5e-8 vs relu ≈ 6.3e-5. Heatmap norms show sigmoid `‖∂L/∂w‖` ~1e-8 per layer
vs relu ~1e-5.

## 2026-09-02 20:15

**Discussed:** User pointed out the `RMS(∂L/∂w)` vs depth panel was flat
(anticlimactic) and approved adding the cleaner measure ("okay you can add
measure/activation").

**Decision:**
- Added `backward_capture(model, grad_out)` — replicates `Sequential.backward`
  (still accumulates into `w.grad`) but returns `delta = ∂L/∂z` at the input of
  every Linear layer (input→output order). Replaces the `model.backward(...)`
  call in the training loop. No `basicml/` change.
- New history key `dnorm` = per-layer `RMS(delta)`.
- Bottom-left panel now plots `RMS(delta)` (solid + markers) per model, with
  `RMS(∂L/∂w)` kept as a faint dotted line for contrast. Suptitle ratio switched
  to `‖delta_L1‖/‖delta_last‖`.

**Result (400-epoch run):** the panel is now the textbook staircase — sigmoid
`RMS(delta)` a straight log-line from ~3e-12 (layer 1) to ~1e-3 (layer 13),
~10 orders across depth; relu `RMS(delta)` flat ~1e-6. Ratio
`‖delta_L1‖/‖delta_last‖`: sigmoid 2.5e-9 vs relu 0.77. The dotted `∂L/∂w` lines
stay flat — confirming why `∂L/∂w` alone hid the effect (forward activations
compensate).
